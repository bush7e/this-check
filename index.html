🧾 ค่าอินเทอร์เน็ต 3BB: ค้นหาศูนย์และดูสถานะรายเดือน

เลือกรายชื่อ → ตรวจยอดรายเดือน → พิมพ์ใบเบิก

เข้าสู่ระบบเป็น
ค่าบริการส่วนเกิน (ไม่มีก็เว้นว่าง)
ใช้ได้ทั้งเพิ่มรายการใหม่ และเพิ่ม/แก้ยอดของเดือนในรายการเดิม ข้อมูลเก็บไว้ในเครื่องนี้ ถ้าต้องการให้ทุกคนเห็น กด "⬇️ ดาวน์โหลดไฟล์ปัจจุบัน" แล้วอัปโหลดทับบน GitHub
ไฟล์ต้องมีหัวคอลัมน์เหมือนไฟล์ตัวอย่าง (data.xlsx / phone.xlsx) ข้อมูลที่เพิ่มจะใช้และเก็บไว้ในเครื่องนี้เท่านั้น ถ้าต้องการให้ทุกคนเห็นเหมือนกัน ให้อัปโหลดไฟล์ทับบนเว็บ

☁️ อัปเดตขึ้นเว็บ (GitHub)

ส่งไฟล์ข้อมูลล่าสุดขึ้น GitHub ให้โดยตรง แล้ว GitHub Pages จะอัปเดตเว็บให้ทุกคนเห็นภายใน 1-2 นาที ต้องใช้ โทเคนของ GitHub (สร้างครั้งเดียว)

  1. GitHub → รูปโปรไฟล์ → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → เลือกเฉพาะ repo ของเว็บนี้
  3. Permissions → Contents: Read and write
  4. กด Generate แล้วคัดลอกโทเคนมาวางด้านล่าง (ห้ามส่งให้ผู้อื่น)

ตรวจสอบก่อนรวมข้อมูล

❓ วิธีใช้งาน

เบิกทุกเดือน (3 ขั้นตอน)

  1. เลือกเรื่องและรายชื่อ เลือกอินเทอร์เน็ตหรือโทรศัพท์ แล้วเลือกศูนย์/เบอร์ หรือกดชื่อจากรายการ "ยังไม่จ่าย" ในการ์ดสรุป
  2. ตรวจสถานะรายเดือน ดูว่าเดือนไหนจ่ายแล้ว แล้วกดการ์ดเดือนที่ต้องการเบิก
  3. ตรวจข้อมูลแล้วพิมพ์ เช็กผู้จัดทำ ผู้อนุมัติ วันที่ แล้วกด "Print บันทึกภายใน"

ผู้ดูแลข้อมูล

  • ➕ เพิ่มข้อมูลใหม่ กรอกเบอร์/ศูนย์ เดือน วันที่ ยอด (ใส่รายละเอียดบิลโทรศัพท์ได้) แล้วกดบันทึก
  • ให้ทุกคนเห็นข้อมูลที่เพิ่ม กด "⬇️ ดาวน์โหลด" ได้ไฟล์ Excel ใหม่ แล้ววางทับไฟล์เดิมบนเว็บ
  • 📁 อัปโหลดไฟล์ Excel หรือ ลากไฟล์ .xlsx มาวางบนหน้าเว็บ ข้อมูลในไฟล์ใหม่จะ รวมเข้ากับข้อมูลเดิมทันที (ศูนย์/เบอร์ที่มีอยู่จะอัปเดตเฉพาะช่องที่ไฟล์ใหม่กรอกไว้ ข้อมูลเก่าไม่หาย)
  • ☁️ อัปเดตขึ้นเว็บ (ในแถบเหลือง) ส่งไฟล์ขึ้น GitHub โดยตรง ทุกคนเห็นข้อมูลใหม่ภายใน 1-2 นาที (ต้องตั้งโทเคนครั้งแรก)
  • 💾 บันทึกลงไฟล์ (ในแถบเหลือง ใช้ได้ใน Chrome/Edge) เขียนข้อมูลลงไฟล์ในโฟลเดอร์ของคุณโดยตรง ไม่ต้องดาวน์โหลดแล้ววางทับเอง

ควรรู้

  • ในไฟล์ Excel ช่องค่าบริการ มีตัวเลข = จ่ายแล้ว ว่าง = ยังไม่จ่าย
  • แถบเหลือง "แสดงข้อมูลในเครื่องนี้" แปลว่ายังไม่ใช่ไฟล์จริงของทุกคน กด "กลับไปใช้ไฟล์บนเว็บ" เมื่อใช้ทดลองเสร็จ
  • เข้าสู่ระบบด้านบนเฉพาะเมื่อต้องอนุมัติ/บันทึกจ่ายเงิน (ค้นหาและพิมพ์ใบเบิกไม่ต้องเข้าสู่ระบบ)
  • หน้าเว็บไม่เปลี่ยนหลังอัปโหลดไฟล์ใหม่ ให้กด Ctrl+F5
